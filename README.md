# Don't Take the Bait – Phishing Awareness

## Description
An interactive web-based phishing awareness module designed to teach users how to identify phishing attacks, understand social engineering tactics, and respond safely.

## Features
- Explains different types of phishing:
  - Email Phishing
  - Spear Phishing
  - Whaling and BEC
  - Smishing
  - Vishing
  - Quishing
- Identifies common phishing warning signs.
- Interactive activity for spotting red flags in a fake email.
- Explains how to recognize fake websites and suspicious URLs.
- Covers common social engineering tactics.
- Includes real-world phishing cases.
- Provides best practices for staying safe.
- Includes an interactive phishing quiz.

## How to Run
Open `Task2.html` in any modern web browser.

No server or installation is required.

## Navigation
- Click **Next** and **Back** to move between sections.
- Use the **Left ←** and **Right →** arrow keys for navigation.
- Complete the interactive activity and quiz.

## Safety Reminder
The main message of the module is:

**Stop, Look, Verify.**

Always verify suspicious messages through a separate trusted channel before clicking links, opening attachments, or sharing information.
